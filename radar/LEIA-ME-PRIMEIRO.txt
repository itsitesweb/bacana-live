  Instalação Self-Service para Alunos

OLÁ! ESTE ARQUIVO TEM A SEQUÊNCIA EXATA QUE VOCÊ PRECISA SEGUIR.
LEIA INTEIRO ANTES DE COMEÇAR (são só 2 minutos).


┌─────────────────────────────────────────────────────────────┐
│  PASSO 1 — MOVER A PASTA PARA O LOCAL CERTO                  │
└─────────────────────────────────────────────────────────────┘

  → Pega a pasta chamada "trading-terminal" que está DENTRO
    deste zip e copia ela para:

         ~/Documents/trading-terminal

  ATENÇÃO: tem que ser EXATAMENTE esse caminho. Os scripts
  esperam encontrar a pasta lá.

  COMO FAZER NO MAC:
  ─────────────────
  1) Descompacta este zip (geralmente já vem descompactado se
     baixou pelo navegador)
  2) Abra o Finder
  3) Arraste a pasta "trading-terminal" para "Documentos"

  Resultado esperado:
  Você consegue ver a pasta em /Users/SEU_USUARIO/Documents/trading-terminal


┌─────────────────────────────────────────────────────────────┐
│  PASSO 2 — DAR DUPLO-CLIQUE NO INSTALADOR                    │
└─────────────────────────────────────────────────────────────┘

  → Encontra o arquivo "instalar.command" (está NESTE mesmo
    zip, ao lado deste LEIA-ME).
  → Dá DUPLO-CLIQUE nele.

  O QUE VAI ACONTECER:
  ────────────────────
  Vai abrir uma janela do Terminal automaticamente. O script
  vai instalar tudo que você precisa: Python, dependências,
  Playwright. Demora uns 10-15 minutos.

  Se aparecer mensagem do Mac dizendo
  "instalar.command não pode ser aberto":
    → Clique com o BOTÃO DIREITO no arquivo
    → Escolha "Abrir"
    → Confirma no aviso que aparecer

  Quando terminar, vai aparecer no Terminal:
    ✅ INSTALAÇÃO CONCLUÍDA


┌─────────────────────────────────────────────────────────────┐
│  PASSO 3 — CONFIGURAR SEU BOT DO TELEGRAM                    │
└─────────────────────────────────────────────────────────────┘

  → Abra o documento docs/Guia_de_Configuracao_Aula.md
    (ou o PDF que veio com o curso)
  → Vá direto na AULA 4 — "Criar bot do Telegram"
  → Siga até o fim da Aula 6 — "Configurar arquivo .env"

  É a parte que você não pode pular — sem o bot, o sistema
  roda mas você não recebe os alertas.


┌─────────────────────────────────────────────────────────────┐
│  PASSO 4 — INICIAR A OPERAÇÃO                                │
└─────────────────────────────────────────────────────────────┘

  → Abra o Terminal (Cmd+Espaço → digite "Terminal" → Enter)
  → Cole este comando exato e aperte Enter:

       cd ~/Documents/trading-terminal && ./start_daemon.sh

  → Sistema vai começar a rodar. Você vai ver mensagens
    como "DISCOVERY", "SCAN #1", etc.
  → A linha "Telegram: PRONTO" confirma que vai chegar
    alerta no seu celular.


════════════════════════════════════════════════════════════════
  DEU ERRO? LEIA ANTES DE ABRIR TICKET DE SUPORTE:
════════════════════════════════════════════════════════════════

  → Abra docs/Guia_de_Configuracao_Aula.md
  → Vá no Apêndice B — "Erros comuns e soluções"
  → 90% dos problemas estão lá com solução pronta.

  Os 5 erros mais comuns:

  1. "command not found: python3"
     → Você pulou o Passo 2 (não rodou instalar.command).
       Volta no Passo 2.

  2. "Telegram: OFF" ou "Telegram: ERRO"
     → Você não configurou o .env (Passo 3 incompleto).
       Volta na Aula 6 do Guia.

  3. "Watchlist: 0 jogos" por mais de 30 minutos
     → Provavelmente está de madrugada. Sistema só monitora
       quando tem jogo ao vivo. Espera os jogos da tarde/noite.

  4. Sistema "parou de funcionar"
     → Abre o Terminal e roda:
         cd ~/Documents/trading-terminal && ./start_daemon.sh
       O start_daemon.sh tem auto-restart embutido.

  5. "Erro de permissão" ao rodar o instalar.command
     → Botão direito no arquivo → Abrir.
